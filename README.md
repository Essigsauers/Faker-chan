# Faker Chan для Insomnia

Faker Chan генерирует синтетические тестовые значения прямо в запросах Insomnia

## Быстрый старт

1. Поставьте курсор в URL, query-параметр, заголовок, тело запроса или поле аутентификации
2. Нажмите `Ctrl+Space`
3. Введите `FakeC` в поиске Template Tags
4. Выберите тег и заполните его параметры, если они есть

Теги возвращают готовое значение без кавычек

```json
{
  "email": "<тег FakeC - Contact Email>",
  "requestId": "<тег FakeC - Identifier UUID>"
}
```

Insomnia вставляет выражение тега в выбранное поле автоматически

## Возможности

- Идентификаторы, персональные и контактные данные, адреса, координаты, даты, числа и строки
- Тестовые JWT и распространённые HTTP-заголовки
- Последовательный `Counter` с областями `Request`, `Folder`, `Workspace` и `Global`
- Сохранение нового значения счётчика при отправке запроса
